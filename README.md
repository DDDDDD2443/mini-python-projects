# Mini Proiecte Python 🐍

Acest repository conține o colecție de proiecte simple realizate în Python, ideale pentru începători și pentru a demonstra abilitățile de programare.

## 📁 Proiecte incluse

1. **Radacina patrata**: Calcularea rădăcinii pătrate a unui număr prin două metode.
2. **Calculator simplu**: Realizarea unui calculator care efectuează operații de bază.
3. **Convertor de temperatură**: Conversia temperaturii între Celsius și Fahrenheit.
4. **Facecontrol concert**: Verificarea accesului la un concert în funcție de vârstă și bilet.
5. **Admitere permis auto**: Verificarea eligibilității pentru examenul de permis auto.

## 🔧 Tehnologii utilizate

- Python 3.x
